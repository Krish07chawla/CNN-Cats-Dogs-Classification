# 🐱🐶 Cats vs Dogs Binary Image Classification using CNN

## 📌 Project Overview

This project implements a **Binary Image Classification system** using a **Convolutional Neural Network (CNN)** to classify images into two categories:

- 🐱 Cat
- 🐶 Dog

The project was developed using **Python and PyTorch** and covers the complete deep learning workflow:

1. Dataset preparation
2. Train/Validation/Test splitting
3. Image preprocessing
4. Data augmentation
5. CNN architecture design
6. Model training
7. Validation
8. Best model selection
9. Overfitting analysis
10. Final test evaluation
11. Performance analysis using Accuracy, Precision, Recall and Confusion Matrix

---

# 🎯 Problem Statement

Image classification is a fundamental computer vision task where a machine learning model learns to identify the class of an image.

The objective of this project is to develop a CNN that can automatically determine whether an input image contains a **Cat or a Dog**.
